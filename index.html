☁️ Gist do FB Radar

Por onde o PC manda os anúncios e os avisos para o celular. Cole um token do GitHub só com a permissão gist (gerar token). Se já existir um Gist do FB Radar na conta, ele é reaproveitado.

📍 Cidades

Só entram anúncios destas cidades (uma por linha). Vazio = todas as que o Facebook mostrar.

📱 Configurar o celular

No celular, abra o FB Radar → Configurações → Ler QR do PC e aponte para este código (ou aponte a câmera do celular direto, para abrir já configurado).

🔗 Conectar ao PC

No PC, abra o FB Radar (localhost:5500/fb) → Configurações → Mostrar QR code.

🧩 Coletor (no PC)

A extensão FB Radar Coletor (pasta coletor) roda no Chrome do PC, logado no Facebook, e confere a categoria Consoles de Video Game a cada poucos minutos. Ligue pelo ícone dela (▶ Iniciar).
